Benvenuto nel mio repository di **Software Quality Assurance (QA)**. Questo progetto illustra una strategia di testing end-to-end applicata alla piattaforma e-commerce **SauceDemo**, integrando metodologie di test manuale basate sugli standard **ISTQB**, verifica di basi di dati tramite **SQL** e un'introduzione all'**Automation Testing** con Python e Selenium.

---

## 📁 Architettura e Struttura del Repository

Il progetto è organizzato nelle seguenti sezioni chiave:

```text
qa-portfolio-saucedemo/
│
├── TEST_PLAN.md                     # Documento strategico di pianificazione test (ISTQB)
│
├── test-cases/
│   └── TC_SauceDemo_Functional.md   # Test Case funzionali (EP, BVA, State Transition)
│
├── bug-reports/
│   └── BUG_REPORTS.md              # Report delle anomalie riscontrate (Stile Jira)
│
├── sql-queries/
│   └── database_verification.sql    # Query SQL per la verifica della consistenza dati
│
└── automation/
    └── test_saucedemo_login.py     # Script Python + Selenium per l'autotesting di Login
